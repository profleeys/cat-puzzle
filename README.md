# 🐱 貓咪拼圖 (Cat Placement Puzzle - 6x6)

這是一款以**經典皇后拼圖 (Queens Puzzle / Star Battle)** 為核心規則、專門為貓咪主題打造的 6x6 益智休閒解謎遊戲。

---

## 📖 核心遊戲規則

1. **🎨 每種顏色一隻貓**：棋盤共劃分為 6 個不同顏色的連通區域，每個顏色區域內**只能且必須放置一隻貓咪**。
2. **↔️ 同行同列僅一隻**：每一行（Row）與每一列（Column）**只能有一隻貓咪**（共 6 行 6 列，放置 6 隻貓）。
3. **🚫 貓咪不能挨在一起**：貓咪的周圍 8 格（前後、左右、斜角相鄰）**不能有其他貓咪**（即切比雪夫距離 $\ge 2$）。
4. **⭐ 尋找 1 格的起點**：遊戲每關開局必定有一個顏色**只有 1 個格子**，該格子保證就是該顏色唯一的貓咪位置，是玩家的破局突破口！
5. **✖️ 標記 X 機制**：玩家可標記「X」排除不能放貓咪的格子，輔助邏輯推演。
6. **❤️ 3 顆愛心生命挑戰**：若點擊放置了違背規則的格子，會扣除一顆愛心並標記紅色 X（如附圖展示）。

---

## ✨ 遊戲特色功能

- **🎯 截圖關卡 1:1 復刻**：第一關即為題目附圖中的經典關卡，色彩、貓咪站位、單格紫色起點完全一致。
- **🎨 精緻 SVG 貓咪插畫**：
  - 可愛黑白賓士貓（Tuxedo Cat）立體胖嘟嘟臉蛋、粉嫩小鼻子。
  - 左下角眨眼貓（Wink Cat）搭配閃爍星芒 ✨。
- **🔊 Web Audio API 萌趣音效**：
  - 放置貓咪：「喵嗚～ (Meow~)」可愛貓叫。
  - 放置 X：「啪嗒」清脆木質點擊聲。
  - 規則衝突：「唔？」柔和警示音。
  - 勝利通關：清脆悅耳的勝利揚聲樂曲。
- **⚡ 自動補 X 輔助功能 (Auto-X)**：放置貓咪後自動為同行、同列、相鄰 8 格與同色區域補上 X，省去繁瑣重複點擊（可隨時在設定切換開啟/關閉）。
- **↩️ 復原 (Undo) 與 💡 智慧提示**：具備多步驟步數復原，並可依盤面現狀給予啟發式邏輯提示。
- **🎲 無限隨機謎題生成器**：內建 Procedural Level Generator，演算法保證生成的謎題必有唯一解（Unique Solution）且包含 1 格的起點標記。
